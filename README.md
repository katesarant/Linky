# Linky

**Your links. Your work. Your time.**

Linky is a lightweight web project for bringing useful links and online content together in one place. The project is being developed with a simple, responsive front-end approach.

</a>


## ✨ Technology Stack

| Technology | Purpose | Documentation |
|---|---|---|
| HTML5 | Page structure and semantic markup | [MDN HTML](https://developer.mozilla.org/en-US/docs/Web/HTML) |
| [Bootstrap](https://getbootstrap.com/) | Responsive layout and UI components | [Documentation](https://getbootstrap.com/docs/) |
| [Bootstrap Icons](https://icons.getbootstrap.com/) | Icon library | [Icons documentation](https://icons.getbootstrap.com/) |
| [Bootswatch](https://bootswatch.com/) | Ready-to-use Bootstrap themes | [Themes](https://bootswatch.com/) |
| [GitHub Pages](https://pages.github.com/) | Static website hosting | [Documentation](https://docs.github.com/en/pages) |


## 📁 Project Structure

The repository currently contains the README and license. Add the website files to the repository root (including `index.html`) as development progresses.

A possible structure is:

```text
Linky/
├── index.html
├── assets/
│   ├── css/
│   ├── js/
│   └── images/
├── LICENSE
└── README.md
```
